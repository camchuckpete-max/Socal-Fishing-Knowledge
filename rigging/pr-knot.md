# PR Knot — Bobbin-Tied Braid-to-Leader Connection

A braid-to-leader connection knot tied with a weighted **PR bobbin** tool
rather than by hand tension — presented on Tackle Express as the alternative
to the [FG knot](fg-and-albright.md#parameters--judgment) for the same
braid-to-leader job, with the tool doing the work of keeping tension
consistent rather than the angler holding it.

**Not the same knot as the "RP knot"** documented in [Essential SoCal
Knots](essential-knots.md#parameters--judgment) (a doubled-fluoro-loop
construction, 6-up/6-down wraps, named for the *Royal Polaris*) — that is a
different, unrelated tie. The near-identical name (PR vs. RP) is a
source-corpus coincidence, not the same knot; kept as separate notes so the
names aren't conflated.

## When to use it

- Reach for the PR knot where you want a **tool-assisted**, low-variance
  braid-to-leader connection instead of hand-tensioning the FG knot — the
  presenter's framing is a direct alternative for the same job, not a
  different use case.
- **Presenter's own track record:** he states he has fished the PR knot for
  about 10 years (i.e., since approximately 2015, dated off this clip's
  2025-06-11 upload) and has never had the knot itself fail — he has had
  spectra break above the knot and mono break below it, but never the knot.

## Parameters & judgment

- **Tool:** tied with a PR bobbin, described as carrying its own weight so
  that spinning it lays the wraps down evenly and keeps constant tension on
  the line automatically through the tie.
- **Contrast — FG knot tied by hand (same clip):** the FG ("friction grip")
  knot needs no tool but must be tied very tight with consistent tension held
  by the angler throughout; the presenter has observed FG knots tied "rather
  quickly" and not exactly correctly slip out and fail. See [FG Knot &
  Albright Knot](fg-and-albright.md#parameters--judgment) for the full FG
  build spec (wrap count, tensioning method, finishing taper).
- **Strength claim, destruction-testing machine (secondhand citation, not the
  presenter's own test):** referencing unnamed "videos out there with chill
  guys testing the knots," the PR knot is cited at **100%** — called "the
  only 100% knot out there" — versus the FG knot at approximately **98%**.
  No testing source, sample size, or line class is given; preserved as a
  claim attributed to the clip, not independently verified here.
