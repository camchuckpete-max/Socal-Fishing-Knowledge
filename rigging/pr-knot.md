# PR Knot — Bobbin-Tied Braid-to-Leader Connection

A tool-tied braid-to-leader connection knot: a weighted **PR bobbin** spins to
lay the wraps down evenly and hold constant tension automatically, replacing
the angler's hand tension (`To2Dvx3Ifnc`). Presented as a direct,
tool-assisted alternative to the [FG knot](fg-and-albright.md#parameters) for
the same braid-to-leader job — same use case, not a different one. Not the
same knot as the [RP Knot](rp-knot.md) (a doubled-fluoro-loop construction
named for the *Royal Polaris*) — the near-identical name is a source-corpus
coincidence, not a shared tie.

## When to use

- Reach for the PR knot for a tool-assisted, low-variance braid-to-leader
  connection instead of hand-tensioning the FG knot — same job, not a
  different use case (`To2Dvx3Ifnc`).
- The presenter has fished the PR knot for about 10 years as of this clip's
  2025-06-11 upload (since approximately 2015) and states he has never had
  the knot itself fail — he has had spectra break above it and mono break
  below it, but never the knot (`To2Dvx3Ifnc`).
- ⚠ Flagged gap — no corpus source: wrap count, line class, or a step-by-step
  build for the PR knot itself. The source is a 98-second comparison
  discussion, not a tying demonstration (`To2Dvx3Ifnc`).

## Parameters

- **Tool:** a PR bobbin carries its own weight, so spinning it lays the wraps
  down evenly and keeps constant tension on the line through the tie,
  replacing hand tension (`To2Dvx3Ifnc`).
- **Contrast — FG knot tied by hand:** the FG knot needs no tool but must be
  held under tight, consistent tension by the angler throughout the tie; FG
  knots tied quickly and not exactly correctly slip out and fail
  (`To2Dvx3Ifnc`). See [FG Knot & Albright Knot](fg-and-albright.md#parameters)
  for the full FG build spec (wrap count, tensioning method, finishing
  taper).
- **Strength claim (destruction-testing machine, secondhand citation):** the
  PR knot is cited at 100% — called "the only 100% knot out there" — versus
  the FG knot at approximately 98%, referencing unnamed third-party
  destruction-test videos ("chill guys testing the knots"); no testing
  source, sample size, or line class is given (`To2Dvx3Ifnc`).
