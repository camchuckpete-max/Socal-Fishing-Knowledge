# DTX Minnow

The Nomad DTX Minnow is a mid-depth trolling swimmer that gets down and holds a
tight action across a wide speed band — a swimmer whose action **dies on heavy
line**, so it fishes the lighter **60–100 lb class**. It rides the **low gunnel
holders** (it's a diver/swimmer, not a surface teaser). Covered here is the
**DTX Minnow 165**.

## Specs

| Parameter | Value |
| --- | --- |
| Class | 60–100 lb class (lighter end keeps the swim alive) |
| Size | 165 (detailed here); HD line adds 180/200/220 |
| Troll speed | 3–12 kt (max depth at 4.5–8 kt) |
| Running depth | 30 ft |
| Setback | 40–60 yd inshore / 80–120 yd tuna |
| Leader / top-shot | 60–100 lb |
| Holder | low gunnel holder |

## How to run it

Fish it on the lighter end of its 60–100 lb class so the swim stays alive, and
run it from a low gunnel holder for depth. It's a calm-day, school-grade
swimmer that gets down to ~30 ft; run it well back (80–120 yd) for tuna.

## HD (heavy-duty) version — hardware differences

Nomad's DTX Minnow HD is a redesigned line built for trolling larger fish,
sold alongside the standard DTX Minnow described above (`f9JOpLrYBiE`). It
differs from the original generation:

- **Harness system:** the original DTX runs a full through-body wire ("Gorilla
  harness") from the tie to the back of the hook, which can bend, break, or
  open on larger fish; the HD replaces it with a full metal matrix plate
  running from the tie to each individual hook harness, eliminating that
  failure mode regardless of fish size (`f9JOpLrYBiE`).
- **Sizes:** the HD line comes in 180, 200, and 220; the standard DTX Minnow
  line covers sizes smaller than 180, including the 165 detailed above
  (`f9JOpLrYBiE`).
- **Autotune ring:** the original ties the autotune eye off through a split
  ring that can bend, open, or warp and presents a sharp edge that can catch
  the line and affect the autotune trolling action; the HD uses a solid ring
  there instead, for truer towing. Both lines share the same autotune
  design/patent otherwise (`f9JOpLrYBiE`).
- **Hooks:** the HD ships with BKK Diablo 5X strong hooks with a larger barb,
  aimed at keeping hooked fish pinned through the fight to the boat; the
  original ships with unspecified stock hooks (`f9JOpLrYBiE`).

No troll speed, running depth, setback, or leader spec is given for the HD
line specifically; treat the running specs above (165) and the wahoo
application specs below (200) as the closest documented analogs pending an
HD-specific figure.

- Calm days, school-grade tuna, or a bite that wants a lively swim — pull the
  DTX over a spreader bar, kite, or speed-trolled [Mad Mac](mad-mac.md); full

  [bluefin trolling](../species/bluefin-tuna-trolling.md).
