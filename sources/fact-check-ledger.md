# Fact-check ledger

Cameron's manual-review queue from the editorial review
(sources/plan-review.md). One row per flag; written by the fact-check and
external-verification passes and by resolve-cites. **A row is a question,
not a verdict** — single-source ≠ wrong; nothing is deleted on the strength
of a flag. Categories: single-source | contradicted-by-source |
contradicted-internal | external-mismatch | cite-unresolved | unverifiable.
The external pass appends ` — verified-current <date> (<source>)` or
` — external-mismatch: …` to the detail cell of rows tagged `ext-verify`.

**Three sections, and only the first is a queue** (Cameron, 2026-08-26 —
"rest you can handle on your own"). The table between the markers holds the
rows that still need something from outside the corpus: each is tagged
`ext-verify` and is an input to `verify-external.yml`, the only workflow with
web access. Below the markers, **Standing** holds rows whose disposition the
KB's own rules already decide — the claim stands under flag, and the note
still carries that flag — and **Resolved** holds rows that are closed, with
how. Rows below the markers are invisible to the dashboard and to the
external verifier by design; they are the record, not the work.
