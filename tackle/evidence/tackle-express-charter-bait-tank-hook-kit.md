channel corroboration are recorded below.

## "Aki Twist" / "Oy Twist" / Owner Aki hook — the unresolved ASR thread

- `IUuP8gGaAAo`: captions render "Aki Twist" for the seabass/squid pick, no
  size given.
- `Q4WWkbc9nag` (Tackle Express, "Tired of Running for Live Bait? Do This
  Instead!", uploaded 2026-04-11, 44 s): same "Aki Twist" spelling, now
  sized 1/0, on a double dropper loop with a scented packaged bait (species
  not named on camera; the packaged-bait product name itself is carried in
  [Bait-Tank Time-Saver](../tackle-express-bait-tank-time-saver.md#pre-scented-berkley-gulp-soft-plastic)
  rather than here).
- `tRlv1azFPlM` (Searcher Sportfishing, "Tackle Tip Thursday Vol. 92 —
  Hooks", 2020-03-26; registered channel, product/model endorsement — low
  confidence per the channel's sponsored-claim caveat, Owner disclosed as a
  Searcher sponsor elsewhere in that note): sizes the Owner Aki hook at 1/0
  for season stock-up — the same size as the `Q4WWkbc9nag` sighting, which
  tilts (but does not confirm) "Aki Twist" toward being the Owner Aki hook
  rather than a separate "Oy Twist" product. See
  [hooks — Owner Aki hook](../hooks.md#owner-aki-hook--season-stock-up-and-channel-islands-sizing).
- The squid-rig "Oy Twist" citation below (`3xx_vES0kdo`, `Eo_bA8IWvyU`) uses
  a close but distinct ASR spelling for the same application family (squid)
  — close enough that "Aki Twist" and "Oy Twist" may be the same Owner
  product misheard two different ways by the same channel's auto-captions,
  but that isn't confirmed either; kept as a separate, still-open data point
  rather than merged.

## Squid — dropper loop and slider

- `3xx_vES0kdo`: "Oy Twist," sized 5 and 7 (read as 5/0 and 7/0 by the size
  match against `Eo_bA8IWvyU` below).
- `Eo_bA8IWvyU` (Tackle Express, 2025-04-16): independently names the same
  hook with the same caption spelling, "Owner Oy Twist," as a long-shank J
  hook for pinning a whole fresh dead squid on a dropper loop — the repeated
  identical ASR string across two separate transcripts supports "Oy Twist"
  as close to the real product name, though it still isn't confirmed against
  a catalog. Gives the sinker range 8–12 oz for the same rig, and the size
  figure "an Oy twist hook between 50 to 70" (read as 5/0–7/0, the same
  slash-dropping ASR pattern that renders "1/0" as "10" elsewhere in this
  corpus).
