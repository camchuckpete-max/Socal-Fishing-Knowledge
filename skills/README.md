# Skills

Deployable skills built FROM the KB. Each skill's `SKILL.md` is hand-authored;
its resource bundle is generated by
[`scripts/build-skill-resources.py`](../scripts/build-skill-resources.py) from
the KB decision layer so it never drifts from the notes.
