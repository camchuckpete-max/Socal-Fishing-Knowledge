# Skills

Deployable skills built FROM the KB.

[`socal-boat-day/`](socal-boat-day/README.md) is the **distributed** skill — the
one that goes to other anglers. It is a thin bootstrap: it hardcodes the repo raw
base and one entry path, then fetches procedure, doctrine, and endpoints live
from `main`. It carries no bundle on purpose, because a packaged skill cannot be
edited after it is sent and a bundle freezes the day it ships.

[`boat-day/`](boat-day/README.md) is the earlier **bundled** design. Its
`SKILL.md` is hand-authored and its resource bundle is generated by
[`scripts/build-skill-resources.py`](../scripts/build-skill-resources.py) from
the KB decision layer, which works for a skill rebuilt in place by its author.

⚠ **Open decision — both define the planning procedure, and two definitions
drift.** Whether `boat-day/` survives as a self-use variant or retires is
Cameron's call; it is flagged here rather than resolved.
