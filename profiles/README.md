# Profiles

Per-user angler data — boat envelope, rod inventory with line classes, tackle
and lure inventories, home port/range, optional spots. Knowledge notes are
universal; everything angler-specific lives here. `cameron/` is the first
user's profile; `_template/` is the blank file set a new user copies to get
sharpened recommendations (see its README for what to provide).
