# Farnsworth Bank

A charted standalone bank at **33°20.560'N 118°31.010'W** (cameron), lying off
the shoreline of the
[Catalina Island — Backside (W→E)](catalina-island-backside.md) zone between Ben
Weston Point and China Point. Two things set it apart from every other spot on
that side: it is **not shoreline structure**, so its read does not start from the
island's orientation ([island structure](island-structure.md)), and it sits
inside a **partial-take closure with a two-species keep list** (`5p6gu14ZC4w`).

## Getting there

**California / CDFW — partial-take SMCA.** Inside the closure area **only
yellowtail and bonito may be kept** — everything else goes back (`5p6gu14ZC4w`).
The spot library records the bank as a partial-take SMCA and refers the boundary
to DFW (cameron). As of 2022-10; registered in
[regulatory claims](../sources/regulatory-claims.md). **Verify the current MPA
boundary and take rules with CDFW before fishing** — the keep list decides
whether a stop here is worth making at all, so it is a planning input, not a
formality.

The bank sits on Catalina's **weather side**, where SoCal's prevailing wind,
current and swell default out of the west, so side selection and swell direction
gate the run before the spot does — the zone-level call is on
[the backside page](catalina-island-backside.md).

⚠ Flagged gap — no corpus source: run distance, heading or time to the bank from
any mainland port, the approach used, and the sea-state envelope the crossing
demands. The only distances the repo carries are between charted positions:
**1.5 nm** from [Ben Weston Point](ben-weston-point.md) up the same shoreline,
and **12.0 nm** from [the 499](499.md), the nearest charted position off the
island (cameron). Those fix where the bank sits relative to the rest of the run;
neither is a run from a port.

## Structure & bathymetry

**This is the corpus's named example of a standalone bank** (`6TBxHnkYXI0`).
Standalone banks rise off the surrounding plain with open water on every side, so
unlike a land-attached perpendicular ridge — which produces only on current
running parallel to the shoreline — a standalone bank **fishes in any current
direction, as long as there is current**. The typology's general caveat is that
each standalone spot still has preferred directions, learned spot by spot
(`6TBxHnkYXI0`, [current structure](../conditions/current-structure.md),
[island structure](island-structure.md)). The general working bias on bank
structure is the **up-current face**, where nutrients are forced up
([current structure](../conditions/current-structure.md)).

Farnsworth itself is a **circular bank** carrying **pinnacles**, and the read
given for it is that those pinnacles **fish about the same from every direction**
— including a current running in toward the island, the set that shuts down the
land-attached spots on the same shore (`6TBxHnkYXI0`).

That typology is the practical reason to keep the bank on the list on a day when
the shoreline spots are gated off: current direction is coherent across a region,
so once the day's set is known the backside's perpendicular ridges can be
pre-judged in or out, while Farnsworth stays in play on whichever direction it
prefers.

⚠ Flagged gap — no corpus source: the bank's charted depth, summit rise, bottom
composition, footprint, how many pinnacles it carries and how they are laid out,
and — against the typology's caveat that every standalone spot has preferred
directions — **which directions this one ranks best**, as opposed to the
fishes-about-the-same read above.

## How it fishes

**The keep list is the first read, not the last.** A stop that can only put
yellowtail or bonito in the box is a different decision from the same stop
anywhere else on the backside, and it is what makes the fall yo-yo window the
bank's headline program rather than one option among several (`5p6gu14ZC4w`).

**Then read current against the typology, not the shoreline.** Being standalone,
the bank is not taken off the list by a current that kills the perpendicular
ridges up and down the same shore — a set running in toward the island is fished
here, where those ridges are done (`6TBxHnkYXI0`,
[island structure](island-structure.md)). The direction still has to be a
direction: the qualifier is current running at all, not which way it runs.

⚠ Flagged gap — no corpus source: the bank's own program — where on it to start,
how the drift is set up, working depths for the [yo-yo](../techniques/yo-yo-iron.md)
drop, tide or light timing, and how long to give it before moving.
