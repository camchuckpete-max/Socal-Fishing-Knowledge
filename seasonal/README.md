# Seasonal

**Route regime-first.** This branch is keyed to the four
[water regimes](../conditions/water-regimes.md) — **winter/upwelling · warming
transition · warm stable · fall fragmentation** (Cameron house doctrine): fish
follow water state, and the months below are only the **typical-year mapping**
of when each regime usually arrives. Each month note opens with a header naming
its regime. In an anomalous year — warm-stable water in March, winter grinding
into May — plan from the regime note and the live water, not the calendar.
