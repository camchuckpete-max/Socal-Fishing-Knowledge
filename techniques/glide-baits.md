# Glide Baits

A **glide bait** is a large, **hard-bodied, jointed** swimbait that kicks
side-to-side on the pause — the European pike/musky-derived class (named
brands: **DS Prestos**, **Jackal**, and other Gucci-style baits). It is a
distinct hard-bait class from soft-plastic [swimbaits](swimbaits.md) and from
[tube baits](../lures/tube-baits.md) (see [Related](#related) for the class
mixup this note previously carried). The one corpus-sourced SoCal program for
this class targets calico bass tight to calm boiler rocks, reached for
specifically when flat conditions let the boat sit close without swell risk
(`XyKF34C5iB4`).

## Reach for this when

- Calm, protected **boiler-rock** structure — not the open kelp/current edges
  [swimbaits](swimbaits.md) covers — when flat conditions let the boat get
  tight to the rocks without swell risk (`XyKF34C5iB4`).
- An occasional change-up for [calico bass](../species/calico-bass.md), not a
  primary presentation — both sourced anglers frame it that way
  (`XyKF34C5iB4`).

## Working the boiler rocks

Wind the bait down with a fast, **"crunching" retrieve** that produces a
zig-zag/pause action — the standard cadence for a European pike/musky-style
glide bait (`XyKF34C5iB4`).

One angler's variant skips the steady wind: **pitch the bait up tight to the
boiler rock, then work it with rod-tip twitches** instead of winding it back.
Holding the bait in place like this keeps it in the strike zone longer and
gives a fish more time to look at it before it clears the spot
(`XyKF34C5iB4`).
