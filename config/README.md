# Config

Runtime configuration the distributed skill reads at plan time. These files
exist so that values which **change** live in the repo, where they can be
edited, rather than inside a packaged skill that cannot be edited after it's
sent.

Right now that means one file: where conditions data comes from, and what to
do when a source lies or dies.
